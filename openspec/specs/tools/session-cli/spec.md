# tools/session-cli Specification

## Purpose

サーバが動いていなくても使える、script 経由のセッション管理を規定する。設定が壊れて起動しないときやプロセスが落ちているときでも、セッションを作る・消す・一覧する口が失われない状態を保つ。

## Requirements

### Requirement: script はサーバ無しで動く

セッション管理の script は、サーバプロセスが動いていない状態でも実行できる SHALL。

#### Scenario: サーバ停止中に畳む

- **WHEN** サーバが動いていない状態で、script によるセッションの削除が実行される
- **THEN** 削除は成立する

### Requirement: script でセッションを作れる（概要必須）

script はセッションの作成を受け付ける SHALL。概要の指定を必須とし、概要を持たないセッションは作られない SHALL。作られたセッションは、endpoint 経由で作られたセッションと同じ形で成立し、以後どちらの経路からも同じように扱える。

#### Scenario: 概要を指定して作る

- **WHEN** 概要を指定して script でセッションを作る
- **THEN** セッションが作られ、endpoint 経由で作られたものと同じ形で進行を始められる。返答には転送予定先（そのセッションの画面1）の URL が返る

#### Scenario: 概要なしでは作れない

- **WHEN** 概要を指定せずに script でセッションを作ろうとする
- **THEN** セッションは作られず、概要が必須であることが伝わる

### Requirement: script でセッションを消せる

script はセッションの削除を受け付ける SHALL。削除が成立したときに何が残らないかは、endpoint 経由の削除と同じとする SHALL。実行中と判定されるセッションの削除は受理しない SHALL。サーバが動いていない経路で何をもって実行中と見なすかは、セッションの保存された状態から判定する。

#### Scenario: script で消す

- **WHEN** 実行中と判定されないセッションの削除が script で実行される
- **THEN** そのセッションに属するものは残らず消える

#### Scenario: 実行中と判定されるセッション

- **WHEN** 保存された状態が実行中を示すセッションの削除が script で実行される
- **THEN** 受理されず、セッションに属するものは何も消えない

### Requirement: script で残っているセッションを一覧できる

script は残っているセッションの一覧を返す SHALL。載る内容は endpoint の一覧と同じとする SHALL。

#### Scenario: script で一覧する

- **WHEN** script で一覧が実行される
- **THEN** 残っている全セッションについて、id・phase・時点情報が返る
