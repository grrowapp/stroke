# access/user-management Specification

## Purpose
管理者が、利用者ごとの許可と、管理者の指名、token が無い接続を管理者として通す接続元を、1つの画面で編集できるようにする。

## Requirements

### Requirement: ユーザー管理画面は管理者だけが開ける

システムは、ユーザー管理画面を `/admin/users` に置かなければならない（SHALL）。管理者でない利用者がこの URL を開いたとき、およびこの画面が使う API を呼んだときは、404 を返さなければならない（SHALL）。

#### Scenario: 管理者が開く

- **WHEN** 管理者が `/admin/users` を開く
- **THEN** ユーザー管理画面が出る

#### Scenario: 一般の利用者が開く

- **WHEN** 管理者でない利用者が `/admin/users` を開く
- **THEN** 404 の画面が出る

### Requirement: 利用者ごとに見せるプロジェクトを選ぶ

システムは、ユーザー管理画面に、利用者（メールアドレス）ごとの行を並べなければならない（SHALL）。各行で、その利用者に許可するプロジェクトを選べなければならない（SHALL）。選べるプロジェクトは、プロジェクト一覧に現れるプロジェクトとする SHALL。

システムは、管理者がメールアドレスを入力して利用者を足せなければならない（SHALL）。利用者を消すと、その利用者の許可はすべて外れる SHALL。

#### Scenario: 利用者を足して許可を付ける

- **WHEN** 管理者が `guest@example.com` を入力して足し、プロジェクト `alpha` を選んで保存する
- **THEN** `guest@example.com` がプロジェクト一覧を開くと `alpha` が出ている

#### Scenario: 許可を外す

- **WHEN** 管理者が `guest@example.com` の行から `alpha` を外して保存する
- **THEN** `guest@example.com` がプロジェクト一覧を開くと `alpha` は出ておらず、`alpha` の URL は 404 になる

#### Scenario: 利用者を消す

- **WHEN** 管理者が `guest@example.com` の行を消す
- **THEN** `guest@example.com` にはどのプロジェクトも出ない

### Requirement: 管理者の指名と管理者として通す接続元を編集する

システムは、ユーザー管理画面で、次の3つを足し引きできなければならない（SHALL）。

- 管理者に指名するメールアドレス
- token が無い接続を管理者として通す接続元ネットワーク（例 `192.168.1.0/24`）
- token が無い接続を管理者として通すホスト名（例 `xxx.grrow.app`）

編集した内容は、保存した後のリクエストから判定に使わなければならない（SHALL）。サーバーを再起動しても失われてはならない（MUST NOT）。

#### Scenario: 管理者を指名する

- **WHEN** 管理者が `lead@example.com` を管理者に指名して保存し、その後 `lead@example.com` がプロジェクト一覧を開く
- **THEN** `lead@example.com` にはすべてのプロジェクトが出ており、タブ bar に「ユーザー管理」が出ている

#### Scenario: 接続元ネットワークを足す

- **WHEN** 管理者が `100.64.0.0/10` を足して保存し、その後 `100.64.1.2` から token 無しで開く
- **THEN** そのリクエストは管理者として扱われる

### Requirement: portal のタブ bar に管理者にだけ入口を出す

システムは、portal のタブ bar の右端に、ユーザー管理画面への入口「ユーザー管理」を置かなければならない（SHALL）。「通知」「プロジェクト一覧」のタブとは離して置く SHALL。この入口は管理者にだけ出し、管理者でない利用者には出してはならない（MUST NOT）。

#### Scenario: 管理者が上層を開く

- **WHEN** 管理者がプロジェクト一覧を開く
- **THEN** タブ bar の右端に「ユーザー管理」が出ており、押すと `/admin/users` が開く

#### Scenario: 一般の利用者が上層を開く

- **WHEN** 管理者でない利用者がプロジェクト一覧を開く
- **THEN** タブ bar に「ユーザー管理」は出ていない
