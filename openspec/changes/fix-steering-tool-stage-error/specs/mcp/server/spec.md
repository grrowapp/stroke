# mcp/server Delta

## ADDED Requirements

### Requirement: その工程で使えないツールは、契約の形で断る

システムは、接続の工程では使えないツールが呼ばれた場合も、他のツールと同じ1階層の結果（`status`・`errorCode`・`error`）を返す SHALL。呼び出し元が結果の形を場合分けせずに読めることを保つ。

`errorCode` は、工程が違うために使えないことを他の失敗（引数の不備・対象が無い・相手に届かない）と区別できる値とする SHALL。

サーバー自身の異常を表すステータスで返してはならない（MUST NOT）。工程の判定は正しく行われており、サーバーは壊れていない。

#### Scenario: 工程外のツールを呼ぶ

- **GIVEN** セッション工程で起動したエージェントが接続している
- **WHEN** そのエージェントが steering 工程向けのツールを実行する
- **THEN** 結果は他のツールと同じ形で返り、`errorCode` から「この工程では使えない」と判別できる

#### Scenario: 他の失敗と区別できる

- **GIVEN** エージェントが工程外のツールを実行して失敗した
- **WHEN** エージェントが結果の `errorCode` を読む
- **THEN** 引数の不備・対象が無い・相手に届かない、のいずれとも違う値であり、引数を直して再試行しても通らないと判断できる
