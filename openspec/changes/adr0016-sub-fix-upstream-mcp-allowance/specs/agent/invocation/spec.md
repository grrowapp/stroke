# agent/invocation Delta

## MODIFIED Requirements

### Requirement: 起動設定は再ビルドなしで変更できる

AI の起動フラグは設定値として外に出す SHALL。既定値は `--setting-sources project` と `--strict-mcp-config` を含む（docs/adr/0001-claude-p-invocation.md）。

`--add-dir` は既定値に**含まない**（MUST NOT）。渡すとリポジトリ配下がまるごと作業場所になり、デバッグログに残る他人のセッションの全文と、`.claude/settings.json` 経由の開発者権限が届く（実測 2026-08-30）。作業場所はその実行の対象（セッションのディレクトリ、または昇格先のプロジェクト）だけとする。

呼び出し側は、引いた起動フラグをそのまま渡すか、その実行に要るフラグを足して渡す SHALL。足すことができるのは呼び出し側だけで、起動処理は渡されたフラグを解釈・補正してはならない（MUST NOT）。

**呼び出しごとに `--allowedTools` へ足してよい MCP ツールは、stroke-board 自身の MCP サーバーのものだけとする SHALL。** 同じ起動に配線する第三者の MCP サーバー（本家 spec-workflow）のツールを `--allowedTools` へ足してはならない（MUST NOT）。

**配線と許可は別のものとする SHALL。** 第三者の MCP サーバーを配線する目的が、その工程で果たす役割に限られ、ツール呼び出しを1つも要さないなら、許可を与えない。配線したことを理由に許可を足してはならない（MUST NOT）。

許可を外しても、その MCP サーバーのツールはエージェントのツール一覧から消えない——`--allowedTools` が決めるのは可視性ではなく許可である（実測 2026-08-30: 許可に載っていない8サーバー・約80ツールが、呼べないまま実行のツール一覧に並んでいた）。**したがって、呼ばせない責務は工程の手順（案内）が併せて負う SHALL。** 手順は、配線されている第三者の MCP を呼ばないことと、その理由を述べる。許可と手順は同じことを述べていなければならず、片方だけが禁じる状態にしてはならない（MUST NOT）。

#### Scenario: 起動フラグを変更する

- **WHEN** 運用者が設定値の起動フラグを変更する
- **THEN** 再ビルドなしに、次回の呼び出しから新しい値が使われる

#### Scenario: 既定の設定で実行する

- **WHEN** 既定の設定で AI を呼ぶ
- **THEN** 開発者個人の設定（`~/.claude/CLAUDE.md`・個人の MCP 設定）はセッションに適用されない

#### Scenario: 対象の外へ出られない

- **WHEN** 既定の設定で AI を呼ぶ
- **THEN** その実行が読み書きできるのは渡された cwd の配下だけで、リポジトリの他のセッションのログには届かない

#### Scenario: 呼び出し側がフラグを足す

- **WHEN** 呼び出し側が設定値の起動フラグに、その実行に要るフラグを足して渡す
- **THEN** 起動には設定値のフラグと足されたフラグの両方が使われる

#### Scenario: 第三者の MCP は配線するが許可しない

- **GIVEN** 承認の後の工程の起動が、本家 spec-workflow の MCP を `--mcp-config` に並べる
- **WHEN** その起動の `--allowedTools` を組み立てる
- **THEN** 載るのは stroke-board 自身の MCP ツールだけで、本家 MCP のツールは載らない

#### Scenario: 配線の目的は許可なしで果たされる

- **GIVEN** 本家 MCP のツールが1つも許可されていない
- **WHEN** 承認の後の工程を起動する
- **THEN** 本家 MCP は起動して登録簿へ自分を書き、その工程の取得・提出は「プロジェクトが登録されていない」で失敗しない

#### Scenario: 許可されていないツールを呼ぼうとする

- **GIVEN** 本家 MCP のツールがエージェントのツール一覧に並んでいる
- **WHEN** エージェントがそのうちの1つを呼ぶ
- **THEN** その呼び出しは実行されず、拒否として返る

#### Scenario: 手順と許可が食い違わない

- **WHEN** その工程の手順が第三者の MCP について述べていることと、その起動の `--allowedTools` の内容を突き合わせる
- **THEN** 両者は同じことを述べており、許可だけが通している状態にも、手順だけが禁じている状態にもならない
