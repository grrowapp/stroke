## ADDED Requirements

### Requirement: 名前の採番は有限回で終わる

同名が存在するときに連番サフィックスで空きを探す処理は、**有限回で必ず終わる** SHALL。上限に達しても空きが見つからない場合、システムは探索を打ち切り、空きが無いことを伝える SHALL。黙って探し続けない。

上限の値そのものは実装が定める。この要件が求めるのは終了条件を持つことである。

#### Scenario: 上限に達する前に空きが見つかる

- **WHEN** `<name>` が存在し、`<name>-2` が存在しない
- **THEN** システムは `<name>-2` を採用する

#### Scenario: 上限まで埋まっている

- **WHEN** `<name>` と、上限までの連番がすべて存在する
- **THEN** システムは探索を打ち切り、空きが無いことを伝え、phase を `proposed` のままにする

#### Scenario: 探索が終わらない状態を作らない

- **WHEN** 承認の操作を行う
- **THEN** 採番の処理は、既存名の数にかかわらず有限時間で応答を返す
