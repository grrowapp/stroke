# configuration Delta Specification

## Purpose

設定がどこで決まり、いつ変えられるかを定める。ビルド時に決まるものと実行時に差し替えられるものの境界、そして変更がいつ動作に現れるかがこの capability の責務である。

## ADDED Requirements

### Requirement: ビルド時に決まる設定は作り直すまで動作に現れない

システムは、ビルド時に決まる設定を実行時の指定で変えない SHALL。値を変えて動作に反映させるには、作り直す必要がある。

#### Scenario: 作り直さずに実行時の指定で変えようとする

- **WHEN** 運用者がビルド時に決まる設定を、作り直さずに実行時の指定で変えて起動する
- **THEN** 動作は変わらず、作り直した時点の値のまま走る

#### Scenario: 変えて作り直す

- **WHEN** 運用者がビルド時に決まる設定を変えて作り直し、起動する
- **THEN** 新しい値で動く

#### Scenario: WS の配信を無効にして作り直す

- **WHEN** 運用者が WS を無効にして作り直し、起動する
- **THEN** 問いと proposal は画面へ配信されない
- **AND** 有効にして作り直すと、また配信される
