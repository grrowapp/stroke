## MODIFIED Requirements

### Requirement: 送れなかった回答は同じ問いのまま送り直せる

システムは回答を送れなかったとき、および AI から応答が得られなかったとき、その旨を示したうえで同じ問いに答え直せる状態に戻す SHALL。問いを失わせてはならない。

回答が受け取られたうえで、AI が前の応答をまだ返していない場合は、これに当たらない SHALL。そのときシステムは失敗を示してはならない（MUST NOT）。待機として示し、ユーザーに同じ問いへ答え直させてはならない（MUST NOT）。

#### Scenario: 回答が送れない

- **WHEN** 回答の送信が失敗する
- **THEN** 送れなかったことが示され、同じ問いに対してもう一度送れる

#### Scenario: AI から応答が得られない

- **WHEN** 回答は届いたが、AI から応答が得られない
- **THEN** 応答が得られなかったことが示され、面は開いたまま同じ問いに対してもう一度送れる

#### Scenario: 前の応答をまだ待っている

- **WHEN** 回答は受け取られたが、AI が前の応答をまだ返していない
- **THEN** 失敗は示されず、待機していることが面の中で示される。ユーザーは何もせずに次の問いを待てる

#### Scenario: 待っている間に次が返る

- **WHEN** 前の応答を待っている状態で、AI が次の問いを返す
- **THEN** 待機の表示は終わり、同じ面に次の問いが現れる。同じ問いへの回答が二重に記録されることはない
