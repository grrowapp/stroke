# mcp/tools/strokes Delta

## Purpose

済んだストロークの記録（末尾が直前の回答）を取得するツールの契約を定める。

## ADDED Requirements

### Requirement: ストローク記録を引数なしで取得する

ツールは引数を取らない SHALL。結果は次のいずれか1つを返す SHALL。

- **記録の一覧**: ストローク記録の一覧。時系列順に並び、最後の要素が最新の記録である
- **エラー**: ステータスとエラー内容

#### Scenario: 記録を読む

- **GIVEN** ストロークを重ねたセッションが存在する
- **WHEN** このツールを実行する
- **THEN** ストローク記録の一覧が時系列順で返り、最後の要素が最新の記録である

#### Scenario: セッションが存在しない

- **GIVEN** 対象のセッションが削除されている
- **WHEN** このツールを実行する
- **THEN** エラーが返り、ステータスとエラー内容を持つ
