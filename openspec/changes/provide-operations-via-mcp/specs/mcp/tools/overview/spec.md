# mcp/tools/overview Delta

## Purpose

セッションの概要（ユーザーが最初に投げた、作りたいシステムの説明）を取得するツールの契約を定める。

## ADDED Requirements

### Requirement: 概要を引数なしで取得する

ツールは引数を取らない SHALL。結果は次のいずれか1つを返す SHALL。

- **概要**: 概要の本文
- **エラー**: ステータスとエラー内容

#### Scenario: 概要を読む

- **GIVEN** 概要を受理したセッションが存在する
- **WHEN** このツールを実行する
- **THEN** そのセッションの概要の本文が返る

#### Scenario: セッションが存在しない

- **GIVEN** 対象のセッションが削除されている
- **WHEN** このツールを実行する
- **THEN** エラーが返り、ステータスとエラー内容を持つ
