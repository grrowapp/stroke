## Purpose

任意の JSON ファイルに対し、スキーマに依存しない汎用の読み取り・編集操作を提供する CLI。`json-edit-lib` の呼び出し口をコマンドラインから使えるようにする。

## ADDED Requirements

### Requirement: 任意の JSON ファイルを編集できる
CLI は、特定のスキーマを前提とせず、任意の JSON ファイルに対して値の取得・設定・削除の操作を受け付ける SHALL。

#### Scenario: 未知の構造を持つファイルの編集
- **WHEN** スキーマの定義を持たない JSON ファイルに対して値の設定操作を実行する
- **THEN** 指定したパスの値のみが変更され、ファイルの他の部分は変更されない

### Requirement: 存在しないパスの操作はエラーとして扱う
指定されたパスが対象の JSON に存在しない場合、取得・削除の操作はエラーを返す SHALL。

#### Scenario: 存在しないキーの取得
- **WHEN** 存在しないパスに対して値の取得操作を実行する
- **THEN** エラーが返り、対象ファイルの内容は変更されない

### Requirement: 書き込みは対象ファイルへの反映を必須とする
値の設定・削除操作が成功した場合、変更は対象ファイルへ書き戻される SHALL。

#### Scenario: 設定操作後のファイル内容
- **WHEN** 値の設定操作が成功する
- **THEN** 対象ファイルを読み直すと、変更後の値が読み取れる
