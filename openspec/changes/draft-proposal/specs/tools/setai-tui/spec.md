## Purpose

`setai-cli` が提供するサブコマンドの操作を、メニュー形式で選択・実行できるようにする対話型のインターフェース。

## ADDED Requirements

### Requirement: TUI は CLI と同じサブコマンド操作を提供する
TUI は、`setai-cli` が提供する各サブコマンドの操作を、メニューから選択する形で実行できる SHALL。TUI 独自の編集ロジックは持たず、対応するサブコマンドの実装を呼び出す SHALL。

#### Scenario: メニューからの編集
- **WHEN** ユーザーが TUI のメニューから対象キーを選ぶ
- **THEN** 対応する CLI サブコマンドと同じ編集結果が得られる

### Requirement: 対応キーの一覧をメニューに表示する
TUI は、起動時に利用可能なサブコマンド（対応する `settings.json` のキー）を一覧としてメニューに表示する SHALL。

#### Scenario: 起動直後のメニュー表示
- **WHEN** TUI を起動する
- **THEN** 現在サポートされている編集対象のキー一覧がメニューとして表示される
