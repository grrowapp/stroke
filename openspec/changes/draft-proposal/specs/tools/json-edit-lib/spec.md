## Purpose

Go プログラムから呼び出せる、スキーマに依存しない JSON 編集の操作を提供するライブラリ。`json-edit-cli` と `setai-cli` はどちらもこのライブラリの上に実装される。

## ADDED Requirements

### Requirement: パス指定で値の取得・設定・削除ができる
ライブラリは、任意の JSON データに対して、パスを指定した値の取得・設定・削除の関数を提供する SHALL。

#### Scenario: パス指定での値の設定
- **WHEN** 呼び出し側がパスと値を指定して設定関数を呼ぶ
- **THEN** 指定したパスの値のみが変更された JSON データが返る

#### Scenario: パス指定での値の削除
- **WHEN** 呼び出し側がパスを指定して削除関数を呼ぶ
- **THEN** 指定したパスの値が取り除かれた JSON データが返る

### Requirement: 編集対象外の値を保持する
編集操作は、指定されたパス以外の値を変更しない SHALL。

#### Scenario: 部分編集後の他フィールドの保持
- **WHEN** JSON データの一部のパスに対して編集操作を行う
- **THEN** 編集対象外だったフィールドは元の値のまま保持される

### Requirement: 存在しないパスの操作はエラーを返す
指定されたパスが対象の JSON に存在しない場合、取得・削除の操作はエラーを返す SHALL。

#### Scenario: 存在しないパスの取得
- **WHEN** 存在しないパスに対して値の取得関数を呼ぶ
- **THEN** エラーが返り、入力の JSON データは変更されない

### Requirement: スキーマ定義を前提としない
ライブラリは、対象の JSON データが特定のスキーマに従うことを前提とした処理を持たない SHALL。

#### Scenario: 未知の構造を持つデータの編集
- **WHEN** 事前に定義されていない構造を持つ JSON データに対して編集操作を行う
- **THEN** 操作は指定したパスに対して成立し、スキーマ違反として拒否されない
