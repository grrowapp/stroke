## Purpose

Claude Code の `settings.json` を、キー単位の責務を持つサブコマンドを通じて安全に編集できるようにする CLI。メインコマンドはルーティングと共通の前処理・後処理のみを担う。

## ADDED Requirements

### Requirement: サブコマンドはキーごとの責務を単独で持つ
setai の各サブコマンドは、対応する `settings.json` のキーに関する読み込み・検証・編集・書き込みの判断を単独で持つ SHALL。メインコマンドはその判断に関与しない SHALL。

#### Scenario: サブコマンドがキー固有の構造を扱う
- **WHEN** あるキーに対応するサブコマンドが実行される
- **THEN** そのキーに許される構造（配列・オブジェクト・文字列等）の解釈と編集は、そのサブコマンドの中で完結する

### Requirement: メインコマンドはキーの知識を持たない
メインコマンドは、サブコマンドへのルーティングと、`settings.json` の読み込み・書き込み・出力制御など共通の前処理・後処理のみを担う SHALL。個々のキーの意味や構造についての知識をメインコマンドに持たせない SHALL。

#### Scenario: 新しいサブコマンドの追加
- **WHEN** 新しいキーに対応するサブコマンドが追加される
- **THEN** メインコマンドの実装は変更を必要としない

### Requirement: サブコマンド名はキー名から機械的に導出しない
サブコマンド名と対応する `settings.json` のキー名は、必ずしも一致しない SHALL。メインコマンドは、サブコマンド名からキー名を抽出するロジックを持たない SHALL。

#### Scenario: キー名と異なるサブコマンド名
- **WHEN** サブコマンド名が対応するキー名と異なる文字列で定義される
- **THEN** そのサブコマンドは正しく対応するキーを編集できる

### Requirement: スキーマに依存しない構成を取る
setai は、`settings.json` 全体を単一のスキーマ定義で検証・編集する構成を取らない SHALL。

#### Scenario: 未対応キーが存在するファイルの読み込み
- **WHEN** setai がサポート対象外のキーを含む `settings.json` を読み込む
- **THEN** 未対応キーの値を変更せずに保持したまま、対象キーのみを編集できる
