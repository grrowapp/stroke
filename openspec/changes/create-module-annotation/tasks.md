## 2. どの面でも注釈を付けられるようにする

現状の面は3つ（整形だけ／生テキストだけ／両方を並べる）で、脇のコメント一覧はどの面でも出したまま。**注釈を付けられる面の制限を外し、面を2つに絞る。**

- [ ] 2.1 整形だけの面で、本文の範囲を選んで注釈を付けられるようにする
- [ ] 2.2 「切り替えるとコメントを付けられます」の断り書きを外す（付けられない面が無くなるため）
- [ ] 2.3 並べて見せる面を落とし、面を2つ（整形された本文・生テキスト）にする
- [ ] 2.4 並べて見せる面に依存していた E2E（`approval-annotation` の `side-by-side`、`upstream-style` の面の切替）を2つの面に合わせる
- [ ] 2.5 一方の面で付けた注釈が、もう一方の面にも出ることを確かめる
- [ ] 2.6 一方の面で消した注釈が、もう一方の面からも消えることを確かめる
- [ ] 2.7 強調やリンクを跨いだ選択に注釈が付き、本文の表示が崩れないことを確かめる
- [ ] 2.8 コードブロックの内側の一部に注釈を付けられ、どちらの面でも同じ範囲を指すことを確かめる
- [ ] 2.9 図の中の一語に付けた注釈が、整形された本文の面では添えられた生テキストの上でその一語だけを指すことを確かめる
- [ ] 2.10 重なった注釈・飲み込まれた注釈・同一範囲の2件目が、どちらの面でも判別できることを確かめる
- [ ] 2.11 `e2e/approval-annotation.spec.ts` に整形された本文からの往復を足す（散文・コードブロックの内側・図の3種）
- [ ] 2.12 差し戻しで送られるペイロードが、どちらの面で付けても同じ形であることを確かめる
