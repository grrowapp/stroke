## ADDED Requirements

### Requirement: 編集の面を広げて使える

システムは、文書を直している間、編集の面を広げて使えるようにしなければならない（SHALL）。広げるかどうかはユーザーが切り替えられなければならず（SHALL）、切り替える口は編集の面そのものに置かなければならない（SHALL）。

広げたときは、下層のナビゲーションを隠して、その分の幅を編集の面に渡さなければならない（SHALL）。元に戻したときは、隠す前の見え方に戻らなければならない（SHALL）。

**編集の面に固定の幅を与えてはならない（MUST NOT）。** 広げた状態でも、面の幅はビューポートの幅に追従しなければならない（SHALL）。読みやすい行長に収めることを理由に上限の幅を設けてはならない（MUST NOT）。左右に余白が残ることは差し支えない。

編集できる6本の文書すべてで切り替えられなければならず（SHALL）、どの画面から開いたかによって切り替えられるかどうかが変わってはならない（MUST NOT）。

#### Scenario: 編集の面を広げる

- **WHEN** 文書を直している面で、広げる操作を行う
- **THEN** 下層のナビゲーションが隠れ、編集の面がその分だけ広がる

#### Scenario: 元に戻す

- **GIVEN** 編集の面を広げている
- **WHEN** 元に戻す操作を行う
- **THEN** 下層のナビゲーションが再び出て、広げる前の見え方に戻る

#### Scenario: ウィンドウの幅を変える

- **GIVEN** 編集の面を広げている
- **WHEN** ウィンドウの幅を広げる
- **THEN** 編集の面の幅もそれに追従して広がる。ある幅で頭打ちにならない

#### Scenario: どの画面から開いても切り替えられる

- **WHEN** 仕様書・ステアリング・承認のいずれの画面から編集できる文書を開いて編集に入る
- **THEN** どの画面でも同じように広げる操作が置かれている

#### Scenario: 編集できない文書を開く

- **WHEN** 編集できない文書を開く
- **THEN** 編集の面が無いので、広げる操作も現れない

### Requirement: 面を広げても現在地と直しかけは失われない

システムは、編集の面を広げている間も、今どのプロジェクトを見ているかと、上層へ戻る導線を見えたままにしなければならない（SHALL）。これらを隠してはならない（MUST NOT）。

面を広げる操作および元に戻す操作は、保存していない変更を捨ててはならない（MUST NOT）。

面を広げているかどうかは URL に含めない（MUST NOT）。同じ URL を開いた人が、こちらの見え方を引き継ぐことはない。

保存していない変更がある状態で画面を離れようとしたときの引き止めは、面を広げている間も働かなければならない（SHALL）。

#### Scenario: 広げた状態で現在地を確かめる

- **GIVEN** 編集の面を広げている
- **WHEN** 画面を見る
- **THEN** 今いるプロジェクトと、上層へ戻る導線が見えている

#### Scenario: 直しかけたまま広げる

- **GIVEN** 保存していない変更がある
- **WHEN** 編集の面を広げる、または元に戻す
- **THEN** 直しかけの内容はそのまま残っている

#### Scenario: 広げた状態の URL を共有する

- **GIVEN** 編集の面を広げている
- **WHEN** その URL を別の場所で開く
- **THEN** 広げていない既定の見え方で開く

#### Scenario: 広げたまま画面を離れようとする

- **GIVEN** 編集の面を広げていて、保存していない変更がある
- **WHEN** 別の画面へ移ろうとする
- **THEN** 引き止められ、離れるか留まるかを選べる
