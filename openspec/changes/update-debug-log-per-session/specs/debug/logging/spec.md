# debug/logging Delta

## MODIFIED Requirements

### Requirement: ログはセッションごとに1ファイルで、過去の呼び出しを失わない

システムは、セッション1つにつきログファイルを1つ作り、そのセッションで呼び出しが完了するたびに追記する SHALL。既に書かれた呼び出しの記録を失わせてはならない（MUST NOT）。

ファイル名だけで「どのセッションのログか」が判別できる SHALL。ファイルの中では、呼び出しの区切りと順序が読み取れる SHALL。

#### Scenario: 2回の呼び出しが1ファイルに時系列で入る

- **GIVEN** デバッグログの出力先が設定されている
- **GIVEN** あるセッションで AI 呼び出しが既に1回完了し、そのセッションのログがある
- **WHEN** 同じセッションで2回目の AI 呼び出しが完了する
- **THEN** そのセッションのログファイルは1つのままで、1回目の記録は残っており、2回目がその後ろに続いている

#### Scenario: セッションで絞り込める

- **GIVEN** 複数セッションの呼び出しログが同じ出力先に溜まっている
- **WHEN** 調査者が特定セッションのログを探す
- **THEN** ファイル名からそのセッションのファイルを1つ特定でき、開けばそのセッションの全呼び出しが順に読める

#### Scenario: 呼び出しの区切りが分かる

- **GIVEN** あるセッションのログに複数回の呼び出しが入っている
- **WHEN** 調査者がそのファイルを読む
- **THEN** どこからどこまでが1回の呼び出しかを判別でき、何回目の呼び出しかが分かる
