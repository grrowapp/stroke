## Context

動機と実測値は proposal.md - Why / Findings を参照。設計上の制約は次の3つ。

- 下層シェルの出どころは prototype 案A だけである。下層ヘッダーは stroke-board 固有で、本家 spec-workflow-mcp に対応する画面が無い。この変更はその prototype から意図的に外れる。
- prototype が読み込む本家 CSS バンドルは `body` に 14px を効かせている。prototype のヘッダーの主題は寸法を書いていないが、実際に出ていた大きさは 14px である。
- 実装側の `--text-base: 14px` は本家の型スケールなので動かせない。

## Goals / Non-Goals

**Goals:**

- 下層ヘッダーの中に、主題 > 戻る導線 の階層を作る。
- prototype から外れる箇所を1点に閉じ、外れた理由がコードから読めるようにする。

**Non-Goals:**

- 型スケールのトークンを触ること。ヘッダーの値はトークンの外側で持つ。
- 上層ヘッダー・パネル見出しの調整。

## Decisions

### 値は戻る導線 16px / 主題 20px。トークンではなく生の px で持つ

24px / 22px を実機で見て「大きすぎる」と判断し、一段下げて決めた。主題と戻る導線の差 4px は、実機で階層がはっきり読める幅として取っている。

型スケールのトークン（`--text-lg` 16px / `--text-xl` 18px）に 20px は無い。主題はトークンに乗せられないので生の px で持つ。戻る導線の 16px は `--text-lg` と同値だが、対になる2つの値の出どころを揃えるため同じく生の px で書く。ここは本家の型スケールに乗らない例外である。

- 却下: `var(--text-xl)`（18px）+ `var(--text-lg)`（16px）。トークンに乗るが、主題が実機で確認した見えより小さい。
- 却下: 主題だけ大きくして戻る導線は 13px のまま。ヘッダー全体を大きく取るという指示に反する。

### 様式は `main.css` の prototype 由来ブロックに置き、`.sb-navitem` より後に定義する

`main.css` の冒頭に「画面ごとに書き散らすと本家とのずれが方々に散るので、ここに集める」と方針がある。ヘッダーの文字サイズも同じ扱いにする。

`.sb-bar-back` は `.sb-navitem` の `font-size: 13px` を上書きする必要がある。両者は詳細度が同じなので、**後に置くこと**で勝たせている。位置に意味があるため、コメントで明示している。

- 却下: `.sb-bar > .sb-bar-back` のように詳細度で勝たせる。位置の制約は消えるが、他の様式が全て単一クラスで書かれている中で1つだけ書き方が変わる。
- 却下: `workspace.vue` に Tailwind の `text-xl` を直書き。`portal.vue` の `text-base` 直書きと同じ「継承・直書きが混在して出どころが読めない」状態を増やす。

### prototype から外れることを様式のコメントに書く

prototype 準拠が原則の層で、そこから外れる。理由を残さないと、後から「prototype と違う」というずれとして再び直されうる。コメントに「値を動かすときは prototype ではなくこの意図を見る」と書いている。

### prototype との突き合わせは実ブラウザの computed 値で行う

当初は prototype の CSS を正規表現で読んで判断し、誤った（本家 CSS バンドルが `body` に効かせている 14px を見落とした）。以後この種の確認は、E2E から `file://` で prototype を開いて computed 値を読む。

## Risks / Trade-offs

- [prototype 準拠という下層シェルの原則が緩む] → 外れる箇所を `.sb-bar-back` / `.sb-bar-title` の2点に閉じ、コメントで理由を明示する。
- [ヘッダーのアイコンと文字の釣り合いが崩れる] → 戻る 16px / フォルダ 14px のアイコンに対し文字が 16px / 20px になる。指示の範囲外なので変えていない。気になる場合は別途調整する。
- [ヘッダーの行高が増え、bar が高くなる] → `.sb-bar` の高さは中身で決まる。サイドバー幅・パネル寸法はヘッダー高に依存しないため、影響は高さのみ。E2E のサイドバー幅 170px のアサーションは通っている。

## Decided

- 対象はシェル上部のバー。パネル見出し（`.sb-panel-title`）は対象外（2026-08-21 ユーザー確認）
- 値は戻る導線 16px / 主題 20px（2026-08-24 実機で確認）
