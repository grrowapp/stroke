# api/session Delta

## MODIFIED Requirements

### Requirement: 残っているセッションを一覧する endpoint を1つ公開する

システムは残っているセッションの一覧を返す endpoint を1つ公開する SHALL。一覧には実体の揃ったセッション——ディレクトリがあり、openspec ルートがあり、ワークフロースキーマが設定済みのもの——だけが載る SHALL。一覧の各件には、セッション id・phase・いつのものかが分かる時点情報が載る SHALL。ai-invocation はこの一覧との符合で初回か継続かを判定する。

#### Scenario: 一覧する

- **WHEN** 一覧が要求される
- **THEN** 実体の揃った全セッションについて、id・phase・時点情報が返る

#### Scenario: 作成直後のセッションは載らない

- **WHEN** 概要の受理直後で、まだ初回の起動が行われていないセッションがある状態で一覧が要求される
- **THEN** そのセッションは一覧に載らない

#### Scenario: 何も残っていない

- **WHEN** セッションが1件も残っていない状態で一覧が要求される
- **THEN** 空の一覧が返る
