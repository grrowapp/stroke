## 実施中に判明したこと

### 証跡の取り方（tasks.md 5章）の jq が、そのままでは通らない

デバッグログには実行の区切りとして `# 2026-08-30 18:36:43.831` の形のコメント行が入る（8回の実行で8行）。tasks.md に載っている

```
jq -r 'select(.message.content) | …' <debugLogDir>/<セッション id>.json
```

は `jq: parse error: Invalid numeric literal` で落ちる。`grep -v '^#'` を挟む必要がある。加えて `.message` が文字列の行が混ざるため、`select(.message|type=="object")` も要る。

### dev サーバーはポートを開いた後もしばらく応答しない

1回目の実行は「画面1（概要の入力）が 5 回開き直しても出なかった」で落ちた。ポートは即座に LISTEN するが、Nitro のビルドに24秒かかり、その間は画面が出ない。`ss` でポートを見て検証を始めると早すぎる。
