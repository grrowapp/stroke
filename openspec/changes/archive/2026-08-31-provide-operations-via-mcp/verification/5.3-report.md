## specs のシナリオとの食い違い（測り方の問題）

`specs/server/session-management` の Scenario「2つのセッションが同時に動いても混ざらない」は、THEN を

> 各セッションの記録に、**自分に対応する識別子（A または B）が少なくとも1回現れ**、かつ他方の識別子は1回も現れない

と書いている。しかし実際には、**エージェントは製品名（識別子）を復唱せず、要件の中身で議論する**ため、自分の識別子も 0 件だった。「他方の識別子が現れない」側は満たすが、「自分の識別子が現れる」側は満たさない。

混在の有無は、上に示したとおり**問いが扱っている文脈**で判定できている。シナリオの THEN は、識別子の出現ではなく「自分の概要に由来する要件を扱っていること」で書くほうが実態に合う。specs の測り方を見直す必要がある（本報告では判定を文脈で行った）。
