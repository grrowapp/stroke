## MODIFIED Requirements

### Requirement: 実行が error に達したら画面が示し、回復はユーザーが選ぶ

システムは、セッションの実行の記録（`invocation`）がリトライ上限到達の終端 `error`（`agent/invocation` が規定する）に達したとき、その状態を画面に示す SHALL。これは完全な失敗（`failure`）にあたり、画面が満たすものは `failure` が定める。

画面は、性質の異なる対処の選択肢を2つ以上提供する SHALL。セッションでは次を出す。

- **再実行** — `api/session/invoke-agent` のキック。リトライ回数はリセットされ、それまでのやり取りは残る。対象を壊さない選択肢はこれである
- **最初に戻る** — セッションを削除（`api/session/delete`）して概要の入力へ戻る。**それまでのやり取りが消える**ため、警告色で示し、消えるものを示した承諾を経てから実行する SHALL。承諾の前に削除してはならない（MUST NOT）
- **一覧へ戻る** — その場で決めずに離れる。セッションは `error` のまま残り、後で開くと同じ選択肢が現れる

閉じる操作の無いモーダルの中であっても、これらの操作には到達できなければならない（SHALL）。`error` のまま操作の無い表示（待機表示など）に置き続けてはならない（MUST NOT）。

#### Scenario: error に達する

- **WHEN** セッションの `invocation` が `error` に変わる
- **THEN** 画面は待機表示をやめて `error` であることを示し、再実行・最初に戻る・一覧へ戻るの操作が現れる

#### Scenario: 再実行する

- **WHEN** ユーザーが `error` の表示から再実行を選ぶ
- **THEN** リトライ回数がリセットされて実行が起動し直され、画面は実行中の表示に戻る。それまでのやり取りは残っている

#### Scenario: 最初に戻る

- **WHEN** ユーザーが `error` の表示から警告色の「最初に戻る」を選ぶ
- **THEN** それまでのやり取りが削除されることを示す確認が出る。承諾するとセッションが削除されて概要の入力へ戻る

#### Scenario: 削除する

- **WHEN** ユーザーが `error` の表示から削除（「最初に戻る」）を選び、消えるものを示した確認を承諾する
- **THEN** セッションは削除され、モーダルが閉じて概要の入力へ戻る

#### Scenario: 最初に戻るを承諾しない

- **GIVEN** 「最初に戻る」の確認が出ている
- **WHEN** ユーザーが承諾せずに閉じる
- **THEN** セッションもそれまでのやり取りも消えておらず、`error` の表示に留まる

#### Scenario: 一覧へ戻って後で再開する

- **WHEN** ユーザーが `error` の表示から一覧へ戻り、後で同じセッションを開く
- **THEN** セッションは `error` のまま残っており、同じ選択肢が現れる

### Requirement: 巡回に拾われない実行の失敗は画面が示し、ユーザーが再試行できる

概要の投稿後の初回起動が実行環境を整えられずに失敗した場合など、セッションが一覧（`api/session/list`）に載らず巡回（`portal/batch`）の対象にならない段階の失敗がある。システムはこの失敗を画面に示す SHALL。これも完全な失敗（`failure`）として扱う——巡回が拾わない以上、システムは自動では何もしないためである。

画面は再試行（`api/session/invoke-agent` の再キック）と、対象を捨てて概要の入力へ戻る操作（`api/session/delete`）を提供する SHALL。後者は**それまでのやり取りが消える**ため、警告色で示し、消えるものを示した承諾を経てから実行する SHALL。

閉じる操作の無いモーダルの中であっても、失敗のまま操作の無い表示（待機表示など）に置き続けてはならない（MUST NOT）。

#### Scenario: 初回起動が失敗する

- **WHEN** 概要の投稿後の初回起動が、実行環境を整えられずに失敗する
- **THEN** 画面は待機表示をやめて失敗を示し、再試行と、概要の入力へ戻る操作が現れる

#### Scenario: 再試行する

- **WHEN** ユーザーが失敗の表示から再試行を選ぶ
- **THEN** 起動が再び要求され、画面は実行中の表示に戻る

#### Scenario: 初回起動の失敗から捨てて戻る

- **WHEN** ユーザーがその失敗の表示から警告色の操作を選ぶ
- **THEN** それまでのやり取りが削除されることを示す確認が出る。承諾するとセッションが削除されて概要の入力へ戻る
