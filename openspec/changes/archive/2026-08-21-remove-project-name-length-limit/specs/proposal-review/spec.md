# proposal-review Delta

## MODIFIED Requirements

### Requirement: プロジェクト名を提案し、ユーザーが確定する

AI は kebab-case のプロジェクト名を提案する SHALL。システムは画面2で名前の候補を当てる際、既存のプロジェクトの名前を除いた候補を当てる SHALL。ユーザーは画面2でその名前を編集し、承認時に確定する。

システムは確定する名前を、受理と保存のどちらでも、長さを理由に拒否しない SHALL。名前の長さに対する製品側の上限を持たない。実行環境がディレクトリ名として受け付けない名前は、プロジェクト生成の失敗として扱う（project-generation が規定する）。

#### Scenario: 提案された名前をそのまま確定する

- **WHEN** ユーザーが提案された名前を変更せずに承認する
- **THEN** その名前が確定名としてプロジェクト生成に渡る

#### Scenario: 名前を書き換える

- **WHEN** ユーザーが画面2でプロジェクト名を書き換える
- **THEN** 書き換えた名前が確定名の候補になる

#### Scenario: 長い名前を確定する

- **WHEN** ユーザーが kebab-case を満たす長い名前を確定して承認する
- **THEN** 長さを理由とする拒否は起きず、その名前が確定名としてプロジェクト生成に渡る

#### Scenario: 候補が既存のプロジェクトと衝突している

- **WHEN** 画面2を開いた時点で、候補と同名のプロジェクトが既に存在する
- **THEN** システムは既存と衝突しない名前に候補を変えて表示する

#### Scenario: 既存のプロジェクトと名前が衝突する

- **WHEN** 確定しようとした名前のプロジェクトが既に存在する
- **THEN** システムは衝突を伝え、別の名前が確定されるまで承認を通さない
