## Why

差し戻しの応答を待っている間に出る文言は、他のストロークで待つときと同じ「AI が次を考えています…」である。差し戻しに対して AI がしているのは proposal を直すことなので、この文言では何が進んでいるのかが伝わらず、AI が修正しているのか、操作が無視されたのかがユーザーには分からない。差し戻し中はそれと分かる表示で示す。

## What Changes

- 差し戻しボタン押下で、「AI が修正中です」をブリンク表示する待ち受け画面に遷移する。修正が返ってきたら proposal 画面に戻る
- この待ち受け画面は「AI が次を考えています…」の待機表示と基本仕様を同じくする（文言のみ違う）。待機中の文言は示す側がその都度与え、共有する表示部品は既定の文言を持たない
- proposal 画面のヘッダーでは待機表示を行わない。待機は遷移先の待ち受け画面で示す
- 待ち受け中も上部固定バーは残す。薄く表示し、操作は受け付けない
- **差し戻し以外のストロークの文言は変えない。** 概要への問いに答えるときも、差し戻しへの問い返しに答えて次を待つときも、質問中なので引き続き「AI が次を考えています…」を示す
- 待機中であることの示し方のうち、点滅は変えない

`add-waiting-animation` の proposal は「`WaitingIndicator` は3箇所で共有される単一コンポーネント」であることを、示し方を揃える手段として挙げている。文言を呼び出し側へ移すことはこの手段を変えるが、点滅と表示の形は共有したままであり、揃える対象から文言だけを外す。

## Capabilities

### New Capabilities

なし

### Modified Capabilities

- `proposal-review`: この change の spec で次を規定する。差し戻しの応答待ちは「AI が修正中です」をブリンク表示する待ち受け画面への遷移とし、修正が返ったら proposal 画面に戻る。問い返し中の待機は、答える面の中で「AI が次を考えています…」が点滅する。待機の文言はいずれも示す側が与える
- `stroke-session`: この change の spec で次を規定する。ストロークの応答待ちの文言は「AI が次を考えています…」とする。待機の文言は示す側が与える（表示は従来どおり）

## Impact

- `app/components/WaitingIndicator.vue` — 既定の文言を廃し、示す側から受け取る
- `app/pages/s/[sessionId]/proposal.vue` — ヘッダーの待機バーをやめ、差し戻し中は「AI が修正中です」の待ち受け画面に遷移する。応答が返ったら proposal 画面に戻る
- `app/pages/index.vue` / `app/pages/s/[sessionId]/index.vue` / `app/components/review/FollowupModal.vue` — 従来と同じ文言を明示で与える。表示は変わらない
