## REMOVED Requirements

### Requirement: 受理された steering の提出を、その起動の作業として記録する

**Reason**: ツールが作業の判定の材料を記録する形は、代行以外の固定の処理をツールに持たせるものであり、`mcp/contract`「代行以外の固定の処理を受け持たない」に反する。提出が受理されたという事実は代行先（本家）が持っており、判定する側が問い合わせれば得られる。ツールがコピーを持つと、記録する者・捨てる者・実行が終わった後に届く応答の扱いがツールの側に生える。

**Migration**: steering 工程の「作業が行われたか」は、実行の終わりに invoke-agent が本家 REST へ問い合わせて判定する（`agent/invocation`「作業が行われたかの判定を工程ごとに持ち、完成の記録より先に問う」）。起動単位の記録とそれを読む経路は削除する。`submit-document` の結果の形は変わらない。
