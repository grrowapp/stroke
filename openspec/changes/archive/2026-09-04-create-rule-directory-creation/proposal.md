## Why

repo 直下にフォルダが増えることへの歯止めが、どの資料にも無い。エージェントは置き場に迷うと直下へ新しいフォルダを作れてしまい、構造がその都度ふくらむ。

一方で、増やしてよい場面は実在する。`docs/specs/` のように、**判断・決定のルールが先にドキュメントへ書かれ、その置き場が後から要る**ようになる形である。禁止だけを書くとこれが通らなくなる。

## What Changes

- `docs/agents/issue-tracker.md` に「フォルダの新規作成」を新設し、`### repo 直下` として規定を置く。**エージェントの自己判断での作成を禁じ、例外を3つに限る**（①初期化・新規プロジェクトの立ち上げ ②スキル・エージェントのプロンプト定義の指示 ③ドキュメント側にルールが先行し、指定フォルダが未作成）
- ③で作った場合の**報告義務**を課す。作成判断の根拠にしたものと、作成したフォルダ名をユーザーへ簡潔に報告する
- `CLAUDE.md` に同じ規定の要点を抜粋し、正が `docs/agents/issue-tracker.md` であることを明記する

**repo 直下のみを対象とする。** 直下以外のフォルダ作成は本 change では扱わない。節を `### repo 直下` として切ってあるので、決まったら並べて足せる。
