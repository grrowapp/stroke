## Question

生成中のプロジェクトの行を、一覧の中でどう見せるか——地の色・中身の薄さ・進行の示し方——と、作成が決着したことをどう知らせるか。

## Variants

prototype は `/prototype/projects`（`app/pages/prototype/projects.vue`）に置き、`?variant=a|b|c` と下部の浮きバー（← → でも切替）で見比べた。一覧は本物の `GET /api/projects` で、生成中と失敗の行は実物が無ければダミーを足している——**バリアントを単体で見ると必ず良く見える**ため、本物の行の中に混ぜて判断した。

生成中の行の地・中身の薄さ・ボケは、バリアントとは別に**スライダーで詰めた**（RGB と透過を `--pt-bg` / `--pt-ink` / `--pt-blur` で受ける）。

- **variant=a**: 決着を中央に浮く帯で知らせる。失敗は静かに落とす
- **variant=b**: 決着を一覧の頭に差し込む帯で知らせる。失敗は赤い柱を立てる
- **variant=c**: 決着を上端のリボンで知らせ、対象の行を光らせる。失敗は警告色に理由を添える

## Chosen

パーツごとに、**見た目・値・id** の3点で置く。id は1セル1つで、行の状態を頭に持つ。

図の読み方。上段の矢印が各セルの幅で、**中の数字は尺**（合計10の比率であって px ではない）。`|` がそのセルの中身の正中線、`(n)` が id の番号である。行そのものを指すものは、右外へ伸ばして下へ折る。

### 生成中の行

| | 決めた値 | 理由 |
|---|---|---|
| 行の地 | `#161f32` を通常の地（`--surface-panel`）の上に重ねる | 下地を敷かずに rgba を1枚置くと、薄めるほどページの地（`#0f172a`）が透けて**暗く沈む**。通常の行と同じ地を敷いた上に色を重ねると、透過が「通常の行にどれだけ自分の色を乗せるか」になる |
| アイコン | フォルダのアイコンを外し、**その位置でローダーを回す** | 行に別部品を増やさない。インデントは他の行と揃えるため、アイコンぶんの幅（14px）は空ける |
| ローダー | 白・帯 180°・太さ 2px・大きさ 15px・回転 0.9s ＋ 明滅 1.6s | 動きはローダーだけが持つ |
| 名前と日付 | 未接続の行と同じ薄さ | 生成中を「薄いだけの行」にしない |
| **行の明滅** | **持たない** | 一覧の行は情報が詰まっており、周期的に薄くすると「進行中」ではなく**読みにくい行**になる。実物で確かめた結果、明滅は行から外した |

**行全体の明滅は、当初の案では持たせるつもりだった**（ユーザーは選択肢から「スピナーと行全体の明滅の両方」を選んでいた）。prototype で実物を見た上で、行からは外すことにした。これは spec に反映済み（`project/generation`「行を明滅させてはならない」）。

| ローダーの値 | 決めた値 |
|---|---|
| 帯の長さ | `180deg` |
| 輪の太さ | `2px` |
| 大きさ | `15px` |
| 回転 | `spin 0.9s linear infinite` |
| 明滅 | `loader-blink 1.6s linear infinite`。`0%, 42%` で `opacity: 1`、`50%, 92%` で `0.25`、`100%` で `1` |

明滅は**ローダーだけ**に掛ける。行には掛けない。2点の行き来にしてあり、`ease` を入れると中間の濃さに留まって U 字に沈む動きになるので `linear` のままにする。明と暗をそれぞれ長く保持し、切り替えだけを短くする。

### 状態のチップ

4状態とも**同じガラスの形**にする。幅は最小 76px で揃え、中身は中央に置く。形（上辺の照り返し・下辺の落ち込み・面の明暗）は共通で、違うのは**灯っているかどうか**だけ。灯るのはアクティブだけで、未接続・生成中はガラスのまま消えている。

| 灯っていないチップ | 決めた値 |
|---|---|
| 文字 | 基調色（`--text-faint`）を **90%** で `#fff` と混ぜる |
| 面 | 180° の階調。**12%** → 4.8%（55%地点）→ 8.4% |
| 枠 | **30%** |

| 灯ったチップ（アクティブ） | 決めた値 |
|---|---|
| 基調色 | `--status-success` |
| 面 | 180° の階調。38% → 20%（55%地点）→ 26% |
| 枠 | 55% |
| 文字 | 55% で `#fff` と混ぜる |
| 文字のにじみ | `text-shadow: 0 0 6px`（60%） |
| 外へのにじみ | `0 0 7px`（45%）と `0 0 15px`（22%）の2枚 |

平らな丸を1つ置くと「点」にしか見えない。斜め上の照り、外へのにじみ、下側の落ち込みを重ねて初めて、球が灯っているように見える。豆を別に並べるのではなく、**チップそのものを灯らせる**。

### 決着の知らせ方

**知らせる面と選ばせるモーダルは別物である。** 順序は 知らせる面 → フェードアウト → モーダル。

| | 知らせる面 | 選ばせるモーダル |
|---|---|---|
| 大きさ | 幅 `min(52rem, 100vw - 4rem)`、高さ `50vh`（画面の半分くらい） | 幅 `min(26rem, 100vw - 3rem)` |
| 位置 | 画面の中央に浮かせる | 画面の中央 |
| 終わり方 | **2.6秒で引き始め、0.42秒でフェードアウト**して自ら消える | **選ぶまで閉じない** |
| 背後 | 暗くしない。`pointer-events: none` で下の一覧を操作できる | `rgb(2 6 23 / 0.55)` で暗くする |
| 文字 | 22px / 700。成功は `#22c55e`、失敗は `#ef4444` | 見出し 15px / 600、補足 12px |

出方は `260ms ease-out` で、下から 4% 上がりながら 0.97 倍から等倍へ。引くときは上へ 4% 抜ける。

**confetti は成功のときだけ。** 面の中央から左右2箇所（`x = 0.34` と `0.66`）へ、1回あたり90粒・広がり70・初速38・寿命160。`prefers-reduced-motion` では出さず、面と文言だけ残す。

**失敗では弾けない。** `name` だけを見ていると、親が名前と結果を同時に更新したときに古い結果で走り、失敗なのに弾ける。両方を見る。

## Borrowed

- **b の「一覧の頭に差し込む」**: 採らない。一覧の並びが押し下げられ、生成中の行の位置が動く
- **c の「対象の行を光らせる」**: 採らない。決着は行より大きな扱いにする、という条件と噛み合わない
- **c の「失敗に理由を添える」**: 決着モーダルの「知らせる面」が引き継ぐ。行ではなくモーダルの中で伝える
