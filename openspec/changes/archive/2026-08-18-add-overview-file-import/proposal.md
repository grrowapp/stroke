## Why

現状、概要入力画面（`/`）はテキストエリアへの手入力のみを受け付ける。作りたいシステムの説明を既にローカルのテキストファイル（`.txt` / `.md`）としてまとめてあるユーザーは、内容を手で貼り直す必要がある。ローカルファイルから直接読み込めるようにし、この手間を無くす。

## What Changes

- 概要入力画面（`StrokeOverviewForm` / `app/components/stroke/OverviewForm.vue`）にローカルファイルを選択する UI を追加する。
- 選択したファイルの中身を読み込み、テキストエリアの内容を**全置換**する（追記ではない）。
- 受け付けるファイルは `.txt` / `.md` のテキスト系のみ。ファイルサイズの上限は設けない。
- `.txt` / `.md` 以外のファイルが選択された場合はエラー表示に留め、テキストエリアの内容は変更しない。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `stroke-session`: 「概要からセッションを開始する」の前段として、概要入力欄にローカルファイルの中身を読み込める手段を追加する。セッション開始そのものの契約（空投稿の扱い、セッション作成条件）は変わらない。

## Impact

- `app/components/stroke/OverviewForm.vue`: ファイル選択 UI とファイル読み込み処理を追加。
- `app/pages/index.vue`: 変更なし想定（`submit` イベントの契約は変わらない）。
- サーバ側 API・状態保存の契約に変更なし。ファイル読み込みはブラウザ内で完結する。
