# stroke-session Delta Specification

## MODIFIED Requirements

### Requirement: セッションの状態を保持する

システムはセッションごとに phase（`stroking` / `proposed` / `approved`）と、履歴に出す記録——問いと回答のペア、および proposal の初提出のマーカー——を保存する SHALL。問い返しの往復もペアとして保存する。会話の全文は保存しない。

#### Scenario: ブラウザをリロードする

- **WHEN** ユーザーがブラウザをリロードする
- **THEN** システムは保存された phase に対応する画面を表示し、履歴も同じ内容で開ける

### Requirement: 履歴はパンくずとして辿れる

システムは済んだ記録を、概要から今までを1本の道として並べたパンくずで示す SHALL。パンくずの1粒は済んだ問い1つ（差し戻しへの問い返しを含む）を表し、**通し番号（Q1, Q2, …）だけ**を表示する。問いや回答の文言を粒に載せてはならない。粒を選ぶと、その問いと自分の回答の全文が開く。proposal が起きた位置はマーカーとして道に入る。今の問いは道の末尾に現在地として置く。

パンくずは常に見えている。開いて閉じる操作を挟まないと過去を辿れない形にしない。

#### Scenario: パンくずを見る

- **WHEN** ユーザーが画面1を見る
- **THEN** 概要から今の問いまでの道が順に並び、済んだ粒は通し番号で示される

#### Scenario: 問いが増えても崩れない

- **WHEN** ストロークを重ねて粒が増える
- **THEN** 粒の幅は番号の長さで決まり、問いの長さに左右されない

#### Scenario: 粒を開く

- **WHEN** ユーザーがパンくずの粒を選ぶ
- **THEN** その問いの全文、そのとき提示された選択肢、および自分が返した回答の全文が開く

#### Scenario: 選んだ選択肢が分かる

- **WHEN** 開いた粒が選択肢を選んで答えた往復である
- **THEN** 提示された選択肢が並び、そのうちどれを選んだかが示される

#### Scenario: 自由入力で答えた往復

- **WHEN** 開いた粒が自由入力で答えた往復である
- **THEN** 提示された選択肢はどれも選ばれていないことが示され、自分が書いた本文が回答として表示される

#### Scenario: まだ1往復もしていない

- **WHEN** 概要を投稿した直後で、まだ回答を1つも返していない
- **THEN** パンくずは概要と今の問いだけになる

#### Scenario: 問い返しの往復も粒になる

- **WHEN** 差し戻しへの問い返しにユーザーが答える
- **THEN** その往復は粒として道に加わり、開くと問い返しの全文と自分の回答が見える

#### Scenario: proposal が道に入る

- **WHEN** proposal が初めて出る
- **THEN** その位置がマーカーとして道に入り、以降の問い返しの粒はその後ろに並ぶ

#### Scenario: ブラウザをリロードする

- **WHEN** ユーザーがブラウザをリロードする
- **THEN** パンくずはリロード前と同じ道を示す

### Requirement: 画面2でも同じパンくずで履歴を辿れる

システムは画面2にも画面1と同じパンくずを置く SHALL。画面2では proposal のマーカーが道に入り、差し戻しへの問い返しの粒があればその後ろに続く。現在地は道の末尾に置く。粒を選んだときの見え方は画面1と同じとする。

画面と画面を移るための専用のリンクは置かない。行き来はパンくずが担う。

#### Scenario: 画面2でパンくずを見る

- **WHEN** ユーザーが画面2を見る
- **THEN** 概要からの道が並び、proposal がマーカーとして道に入り、末尾が現在地として示される

#### Scenario: 画面2で粒を開く

- **WHEN** ユーザーが画面2でパンくずの粒を選ぶ
- **THEN** 画面1と同じく、その問い・提示された選択肢・自分の回答が開く
