# add-full-width-markdown-editor

markdown を編集する面に、**編集領域をブラウザの横幅いっぱいまで広げる切り替えボタン**を付ける。

`create-module-markdown` から委譲された。**親の分割ではなく別の関心事なので、独立した change として扱う**（ADR-0017「委譲の内訳」）。

いま編集面はサイドバーと並んで置かれており、横幅がその残りに制限される。表や長いコードブロックを含む文書を直すとき、1行が折り返して読みづらい。

**やること。**

- 共通の編集 UI（`DocumentEditor`）に、押すたびに広い／元に戻るが入れ替わるボタンを1つ置く
- **広いとき** — サイドバーを隠し、編集領域をビューポートの横幅いっぱいにする
- **元に戻したとき** — サイドバーが戻り、いまと同じレイアウトになる

**適用先は3画面。** 仕様書・承認・ステアリング。いずれも同じ `DocumentEditor` を使うので、そこに置けば3画面に出る。

**やらないこと。**

- **ヘッダーは隠さない。** 広いときも常に見えている
- **ストローク側の proposal 確認画面（注釈 UI）は対象外。** あちらは `DocumentEditor` を使っていない

**完了の目安。**

- 編集 UI にボタンがあり、押すと編集領域がビューポート全幅になる
- もう一度押すと元のレイアウトに戻る
- ヘッダーが常に見えている
- 仕様書・承認・ステアリングの3画面に出て、注釈 UI には出ない

**着手前に確認すること。** `replace-handrolled-with-libraries` が同じ `DocumentEditor` を部分置換している（イベント購読・タイマー・マウント判定をライブラリへ寄せる）。**先に取り込まれる可能性が高い**ので、その後の形に合わせる。競合するのは同一コンポーネントの内部だけで、外から見た振る舞いは独立している。
