# adr0017-sub-update-ui-approval-review

承認まわりの画面を直す。ユーザーが実物を触って挙げた5点。

**1. 差し戻しボタンの位置**

本家と同じく、プレビュー等の面の切替ボタンと同じ並びに置く。現状は面の切替が本文の上、差し戻しは右サイドバーの最下部にあり、離れている。

**2. 承認一覧の「レビューする」をその場で開く**

別画面へ遷移せず、その場で開く（カルーセル相当）。5点のうち一番重い。

**3. 「却下」を「即時却下」に名称変更**

**4. レビュー画面に却下ボタンを設ける**

現状レビュー画面にあるのは差し戻しだけで、承認・却下は承認一覧のカード側にしかない。

**5. 却下の理由入力をモーダルにする**

現状は承認一覧のカードで「却下」を押すとカードの下に理由の欄が開き、その下に「却下する」「やめる」が並ぶ。「却下する」を押すと欄が閉じるだけに見えるため、送信できたのか分からない。

実装を読んだ限り、「理由が入ると上の却下ボタンが送信になる」という設計ではない。上の「却下」は入力欄の開閉を反転するだけで、送信は下の「却下する」が行う。成功すると欄が閉じて一覧を取り直すため、**成功したときのフィードバックが無い**のが分かりづらさの実体である。

レビュー画面の「全体へのコメント」と同じくモーダルで理由を入力させ、モーダルの中で「却下する」「やめる」のどちらかを押す形にする。
