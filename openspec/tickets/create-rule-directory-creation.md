# create-rule-directory-creation

repo 直下への新規フォルダ作成の規定を作る。**エージェントの自己判断での作成を禁じ、例外を3つに限る。**

**例外。**

1. 初期化・新規プロジェクトの立ち上げなど、フォルダ構成そのものを作る工程
2. スキル・エージェントのプロンプト定義に、そのフォルダを作る指示がある
3. 判断・決定のルールがドキュメント側に先行して存在し、指定されたフォルダがまだ無い（`docs/` `docs/specs/` のような場合）

③で作ったときは、**作成判断の根拠にしたものと、作成したフォルダ名をユーザーへ簡潔に報告する。**

**置き場。** 規定の正は `docs/agents/issue-tracker.md`「フォルダの新規作成」。`CLAUDE.md` には要点だけを抜粋する。

**やらないこと。** 直下以外のフォルダ作成は扱わない。節を `### repo 直下` として切ってあるので、決まったら並べて足す。
